# Agent Runtime Kit v0.4.0

This release improves importable-library integration and adds measured operating evidence.
Canonical contract `v1`, schema `0002` and existing explicit shutdown remain unchanged.

## Highlights

- Opt into `AgentRuntime.lifespan(shutdown_timeout_seconds=...)` for checked cooperative shutdown.
  It rejects nested/reopened lifetimes and surfaces `RuntimeShutdownTimeoutError` on incomplete
  cleanup, without owning or disposing application-injected stores, model clients or exporters.
- Follow an application-owned composition guide covering configuration, migrations, resource
  ownership, streaming abandonment, retry boundaries and public/private API expectations.
- Review public runtime/provider signature changes through a committed snapshot, alongside
  canonical OpenAPI, typing, minimal-import and installed-wheel tests.
- Exercise sustained synthetic concurrent turns/tools, slow streams, successful replay, cancellation,
  backpressure abandonment and repeated lifetimes from an external installed-wheel venv.
- Gate CI/Release on task/pool/database-session teardown and retain allocation/thread evidence;
  lower/latest profiles additionally exercise a long-lived shared engine.
- Preserve actual SHA-256-pinned v0.3.1 upgrade state in addition to historical upgrade gates.

## Adoption and limits

The lifetime helper is optional. Existing hosts may retain explicit checked `shutdown()` calls.
Stop/drain ingress before leaving the context and close owned resources afterwards. Timeout or
non-cooperative code still requires host supervision and durable recovery; no tool effects are
rolled back. Shared engine disposal remains the application's decision, not an automatic library
side effect. Create one bounded pool per application lifetime, not per request.

Short synthetic runs are not production capacity or long-term memory certification. The shared
engine control was much flatter than repeated engine churn on the tested host; memory reports
remain informational with no uncalibrated regression threshold. No live provider calls, tenant
authorization platform, scheduler, new database backend or evaluation system are introduced.
