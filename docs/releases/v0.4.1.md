# Agent Runtime Kit v0.4.1

This patch hardens direct importable provider adapters without changing public signatures,
dependency ranges, canonical contract `v1` or schema `0002`.

- Canonical text/message limits now produce safe `ProviderError` for direct generate/stream callers,
  including final stream assembly. Invalid output never emits a successful completion.
- Absent/partial/null usage remains unknown (`None`), not fabricated zero counts. Supplied counts
  must be non-negative JSON integers. Anthropic start/delta usage preserves cumulative semantics.
- OpenAI/Gemini reject unsupported multiple candidates and nonzero/invalid candidate indices rather
  than combining or dropping alternatives. Omitted-index proxies and OpenAI usage-only chunks remain.
- Offline installed-wheel regressions and real PostgreSQL failed-key/no-partial-history checks cover
  these boundaries; release gates add the actual checksum-pinned v0.4.0 preserved-state upgrade.

Hosts should handle unknown usage and inspect proxy fixtures before upgrading. Deltas remain
provisional; error causes/tracebacks are internal diagnostics that can contain provider content.
No live model calls, automatic retries, model-quality certification or production SLA is claimed.

See the [upgrade guide](https://github.com/Shengtao-Lin/agent-runtime-kit/blob/v0.4.1/docs/upgrading-to-v0.4.1.md)
and [provider runbook](https://github.com/Shengtao-Lin/agent-runtime-kit/blob/v0.4.1/docs/runbooks/model-providers.md).
Distribution remains GitHub Releases and GHCR; PyPI is not configured.
