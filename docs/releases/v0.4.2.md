# Agent Runtime Kit v0.4.2

This patch fixes native tool-loop accounting and malformed provider tool-call validation without
changing public signatures, dependency ranges, canonical contract `v1` or schema `0002`.

- Native invocation usage includes every model call, not only the final answer. If any call has
  unknown usage, the invocation total stays `None`. Explicit zeros remain zero. The same rules
  apply to `invoke()`, streaming and generate-only streaming fallback.
- OpenAI-compatible, Anthropic and Gemini adapters reject malformed supported tool identities and
  arguments instead of coercing or silently dropping them. Stream indices must be nonnegative JSON
  integers. Duplicate call IDs within one result and repeated Anthropic tool blocks fail safely.
- Valid fragmented arguments and nullable OpenAI stream placeholders remain supported. A malformed
  later tool call prevents every call in that model result from executing; earlier successful model
  iterations are not rolled back. Text deltas remain provisional until completion.
- PostgreSQL regressions verify aggregate persistence/exact replay and malformed-call failure with
  no tool execution or partial history. External non-editable wheels run 238 provider/native tests.
- Release verification now includes a checksum-pinned actual v0.4.1 upgrade alongside historical
  paths, preserving replay, history, feedback and owner leases. Release Desk remains independently
  pinned to the published v0.4.1 wheel until actual v0.4.2 assets are verified.

Hosts must tolerate unknown totals; token counts are not a billing estimate. Existing stored
responses are not rewritten. Framework-adapter usage envelopes are unchanged. No live model calls,
automatic retries, production load certification or new database migration are introduced.

See the [upgrade guide](https://github.com/Shengtao-Lin/agent-runtime-kit/blob/v0.4.2/docs/upgrading-to-v0.4.2.md),
[runtime runbook](https://github.com/Shengtao-Lin/agent-runtime-kit/blob/v0.4.2/docs/runbooks/runtime.md)
and [provider runbook](https://github.com/Shengtao-Lin/agent-runtime-kit/blob/v0.4.2/docs/runbooks/model-providers.md).
Distribution remains GitHub Releases and GHCR; PyPI is not configured.
