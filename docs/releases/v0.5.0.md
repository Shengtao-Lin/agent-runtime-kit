# Agent Runtime Kit v0.5.0

This release strengthens custom extension contracts and protects the importable library boundary.
Public import paths and documented call signatures remain available; canonical contract `v1`,
PostgreSQL schema `0002` and dependency ranges are unchanged. Custom extensions can nevertheless
fail stricter validation, so review the migration guide before upgrading.

- Canonical model/agent streams require exactly one completion followed by normal EOF and cleanup.
  Completion is withheld until that boundary succeeds; ambiguous streams cannot dispatch tools
  or become durable successes.
- Assistant model results must contain matching ordered message/dispatch tool calls with unique
  IDs. The native invoker revalidates and snapshots results before use. Tool payloads must already
  be finite JSON values; implicit conversion of unsupported Python objects is rejected.
- Core imports no longer eagerly load concrete adapters. Existing public adapter exports resolve
  lazily and retain their direct-module class identity.
- Native/framework policy acceptance covers explicit hook/registry composition, blocked/failed
  outcomes, cancellation and replay. Framework-native bypass and provisional output limits remain
  explicit; this does not introduce a universal policy interceptor.
- CI and release verification guard core-only installed-wheel imports, dependency direction,
  packaged migrations/types, local documentation navigation and canonical ADR identity. Public
  export/extension checks run in external consumers and the expanded lower/latest dependency matrix.
- Preserved-state upgrades add actual checksum-pinned v0.4.2 while retaining v0.1.1, v0.2.0,
  v0.3.0, v0.3.1, v0.4.0 and v0.4.1 paths. Release Desk adoption is verified separately after the
  actual release assets are available.

Native usage aggregation and framework usage semantics remain as documented in v0.4.2. Historical
responses are not rewritten. Output remains provisional until durable completion; failed validation
cannot undo tool effects. No live-provider certification, production capacity claim, database
migration, distributed execution or automatic context truncation is introduced.

See the [migration guide](https://github.com/Shengtao-Lin/agent-runtime-kit/blob/v0.5.0/docs/upgrading-to-v0.5.0.md),
[public API inventory](https://github.com/Shengtao-Lin/agent-runtime-kit/blob/v0.5.0/docs/public-api.md)
and [architecture](https://github.com/Shengtao-Lin/agent-runtime-kit/blob/v0.5.0/docs/architecture.md).
Distribution remains GitHub Releases and GHCR; PyPI is not configured.
