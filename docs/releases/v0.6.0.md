# Agent Runtime Kit v0.6.0

This release adds an explicit initial-context window for applications that retain durable history
but cannot send the entire conversation into every agent invocation. The default remains unchanged.

- Configure `AgentRuntime(context_window=ContextWindow(max_bytes=...))` to keep current requests,
  historical system policy and complete tool exchanges, then the newest whole history groups fitting
  the canonical UTF-8 byte allowance. Mandatory overflow and malformed exchanges fail before dispatch.
- Observe omission and byte counts through runtime context and content-free telemetry. Hooks see
  selected invocation input; successful finalization still appends the original request and output.
  Exact replay, failed-key handling, cancellation and fenced ownership retain their contracts.
- Independent Release Desk workloads compare actual v0.5.0 and the development candidate across
  three repetitions of fifteen profiles. All 972 candidate initial inputs fit the 64 KiB experiment
  allowance. Full history reads remain; RSS is similar and some short workloads are slower.
- Native and real LangChain/LangGraph acceptance covers canonical entry, overflow, failure,
  cancellation, slow consumers, same-thread conflict and restart replay. CI adds bounded workload
  smoke and actual checksum-pinned v0.5.0 preserved-state upgrades while keeping earlier lanes.

The window limits its canonical selector output, not every model call, vendor tokens, database reads
or process memory. Tool results remain whole. No RAG, automatic summarization, distributed execution
or new database schema is introduced. Canonical `v1`, PostgreSQL `0002` and dependency ranges remain.
