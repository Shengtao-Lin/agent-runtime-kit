## Independent operational application

[Release Desk](../../applications/release_desk/README.md) is a separate package/manifest/lock and CLI,
not code inside the library wheel. Its GitHub reader, metadata checklist, deterministic command
router, configuration and resource lifecycle belong to the application. It imports public APIs
only and installs the actual released library, with no FastAPI, framework or model SDK dependency.

The isolated application runner copied it outside the checkout, created its own locked venv and
migrated a dedicated database. Seven pytest cases pass, including command-line feedback retries.
An explicit live canary read this repository's actual public v0.3.0 release metadata once, then
verified cross-process canonical replay, four stored messages and idempotent local feedback.
No GitHub write or provider call was made. Reports live under `build/release-desk-published/`.

## Integration findings

- A feedback retry must preserve its complete payload, including feedback UUID. The application
  derives a stable UUID and scoped key rather than generating a new UUID for each CLI retry.
- Namespace filtering does not define an idempotency or authorization domain. The application
  derives stable agent/feedback key domains from its namespace and documents trusted-local use.
- Explicit installed-wheel migration and `runtime.shutdown()` before engine disposal work without
  importing example/private modules. A minimal PostgreSQL extra is sufficient for this CLI.
- Readiness is an application checklist result, separate from a successful runtime transaction.
  An incomplete checklist is persisted evidence, with CLI exit status 1, not an invented success.

These findings required application integration decisions, not a runtime API change. The public
canary checks metadata only: it does not certify artifact safety, model quality or deployment.
The tag workflow proves the GHCR push; no separate deployed GHCR-image canary is claimed.
PyPI publishing and paid/live model canaries remain unconfigured and unused.
