## Stage D outcome and limits

The measured initial-context gap is resolved by an optional library capability and an independent
host that actually adopts it. The full comparison preserves 972 passing candidate continuations
across three repetitions and fifteen profiles, against the frozen actual-v0.5.0 baseline. Source,
wheel, framework, failure/replay and resource contracts are linked from the acceptance report.

Full history is still read and scanned. The initial canonical byte bound is not a per-model token
limit, a database materialization bound or a process-memory guarantee. Mandatory messages and new
tool results remain whole. Latency results are mixed and instrumented; no production SLO or
capacity claim follows. RAG, automatic summarization, distributed execution, paid provider canaries
and PyPI publication remain outside this delivery. Future work needs a concrete host requirement.
