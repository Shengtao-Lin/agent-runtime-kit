comparison and preserves rejected candidates. [ADR 0016](../adr/0016-history-materialization-and-validation.md)
selects explicit incremental history reads with complete canonical/relationship validation and
column-row consumption. Default materialized reads, durable history and exact replay remain unchanged.

v0.7.0 adds optional public Python capability without changing canonical `v1`, schema `0002` or
dependency ranges. Only root project version metadata changes in `uv.lock`. The
[upgrade guide](../upgrading-to-v0.7.0.md) explains custom-store opt-in, subclass override boundaries,
cursor ownership, unchanged full-scan costs and rollback. Actual v0.6.0 preserved-state/context
upgrades are checksum-pinned in CI/Release; every historical source lane remains.
